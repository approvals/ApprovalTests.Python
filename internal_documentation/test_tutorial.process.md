# Test Tutorial Process

## variables

[TUTORIAL_FILE] = docs/tutorial/minimal-example.md
[DIRECTORY] = [REPO_ROOT]/../.ignore/tutorial/


## process

1. Create the tutorial directory. Clear it if it already exists. 
1. Read the tutorial file and execute it in that directory, step-by-step.
1. Look for things that are missing or incorrect in the tutorial.
1. Report everything that is wrong with the tutorial along with a suggested fix.

Don't delete the directory when you're done.

Show the commands that you used - both the ones that worked and the ones that failed - so we can rerun it ourselves.
